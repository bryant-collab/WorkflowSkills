# Investigation

For an explanation, diagnosis, or recommendation, keep the task read-only. Trace current behavior through [how](../../../how/SKILL.md); use [why](../../../why/SKILL.md) for historical motivation. Answer a narrow, obvious question directly when another workflow adds no value.

Distinguish verified facts, inference, and missing evidence. Give source pointers and consequential constraints, or compare alternatives when a decision was requested. An investigation does not authorize implementation, prototype execution with external effects, a PR, or a status watcher. Return the answer and the evidence that supports it.
