# GitHub delivery

Use the on-demand [github-delivery skill](../../../github-delivery/SKILL.md) for an authorized issue-to-PR change or merge-ready repair. Its [delivery guide](../../../github-delivery/references/delivery.md) owns the procedure and its repository discovery, check selection, single-owner, draft, and authorization boundaries. Load related engineering workflows only when they help the actual task.

This replaces the upstream opening-a-PR integration assumptions with repository-native checks and supported GitHub tools. It does not require a pilot project, router, watcher, or fixed language stack. Follow repository PR conventions and preserve draft work where appropriate. PR creation does not start babysitting or authorize landing.
